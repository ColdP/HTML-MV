# 彗星 / 星街すいせい · 第三版

打开 `Suisei_MV.html`，点击 PLAY FILM。音乐、42 句歌词、四套立绘、Kaisei Decol 与 M PLUS 1 字体、3D 引擎及音频分析均已内嵌。单个 HTML，无需联网或安装依赖。

本版使用连续的世界坐标运镜，36 个路线节点以保持速度连续的单调三次插值连接。镜头推近、环绕、穿行和拉远均在同一个场景中完成；片尾前不使用黑场换景。

| 时间（约） | 场景 |
| --- | --- |
| 0:00–0:27 | 水面天文台：轨道光环、晶体、水面倒影 |
| 0:27–0:59 | 极光剧场：丝幕极光、交错金属拱架 |
| 0:59–1:33 | 月面花园：磨砂透镜、弯曲银色芦苇、石质台阶 |
| 1:33–2:05 | 日食舞台：带凹坑的暗月、发光边缘、半圆阶梯 |
| 2:05–2:28 | 星仪馆：立体浑天仪、环绕球体、空间穿行 |
| 2:28–3:45 | 潮汐剧场：阶梯看台、缎面金属顶棚、环绕与退场 |

材质采用柔光环境反射、PBR 金属与哑光石材、程序化粗糙度和微表面凹凸；增加柔化阴影、人物接触暗部与实时水面倒影。近景降低泛光、关闭色差；高画质使用 4 倍多重采样。人物保持二维原画，以面向镜头的立绘置于真实三维舞台。

立绘在原始分辨率下处理透明边缘颜色，并增加透明留边以减轻缩小时的毛边；不使用整体模糊掩盖边缘。原有发丝透明度保留。原素材本身已有的低分辨率或硬轮廓仍受素材质量限制。

新增 96 条循环流星与 4 颗长尾彗星；轨迹由歌曲时间计算，拖动进度可复现。音画互动使用每秒 50 帧的预分析数据与实时 FFT：低频控制水面与灯光，高频影响星光、极光、粒子和流星亮度。镜头和主歌词不随节拍抖动。

全部 42 句歌词增加英文意译小字（本片译写，非官方译词）。日文保留衬线、黑体、关键词大字、残影和逐字出现等演出；每句歌词锁定一种排版，入场采用三次缓出曲线，完成后停稳。取消句中切换左右位置、持续波浪和轨道漂移，以及 CSS 与逐帧动画叠加造成的拖动。LRC 仅含逐句时间，逐字节奏属于演出编排，不是音素级对齐。

- 空格：播放 / 暂停
- 左右方向键：后退 / 前进 5 秒
- M：静音
- L：同时显示 / 隐藏日文与英文歌词
- F：全屏
- 罗马数字：跳转歌曲章节
- HQ / LQ：切换画质；帧率较低时自动降低分辨率

已检查 JavaScript 语法、离线资源内嵌、运镜节点的连续性、歌词入场后停稳及回拖重建，并在本地 HTTP 预览中检查播放、拖动和响应式画面。浏览器需支持 WebGL 并开启硬件加速。

可编辑源文件保留于 `.work`：`suisei-voyage.js` 构建场景和连续路线，`suisei-direct.js` 控制摄影与固定歌词构图，`suisei-type.js` 控制双语歌词。运行 `build-suisei.py` 重新生成单文件；更换音乐时先运行 `analyze-suisei.py`。V1、V2 HTML 已保存在 `.work`。
