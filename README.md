# HTML-MV

## Suisei — Hoshimachi Suisei MV

Self-contained HTML lyric MV for the Suisei version. Open [`outputs/Suisei_MV.html`](outputs/Suisei_MV.html) in a modern WebGL browser; the audio, Three.js runtime, fonts, and visual assets are embedded in the file.

Preview image: [`outputs/Suisei_MV_preview.jpg`](outputs/Suisei_MV_preview.jpg)

The rendered MP4 exports are kept locally because each file is larger than GitHub's standard 100 MB file limit.
